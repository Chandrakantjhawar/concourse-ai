# Concourse AI ⚽
**Official Submission for Google Prompt Wars Hackathon**
**Challenge Vertical:** Venue & Operations Management Challenge

A production-grade platform that leverages Generative AI to enhance stadium operations, manage crowd flow, and improve the fan experience during the **FIFA World Cup 2026™**.

## 🎯 Problem Statement Alignment
This project is built explicitly for the **Venue & Operations Management Challenge**. It solves the core problem of managing complex, massive-scale events by unifying fans, volunteers, transit authorities, and command center operators into a single AI-driven ecosystem. The solution provides real-time situational awareness and SOP-grounded decision making for stadium operators.

## ⚙️ Approach and Logic
Instead of a generic chatbot, Concourse AI uses a **Retrieval-Augmented Generation (RAG) and structured output approach**.
- **Data-Driven**: The AI is fed real-time JSON context (telemetry, transit data, SOPs).
- **Deterministic Schemas**: We force Gemini to return strict JSON using `responseMimeType: application/json` and validate it using Zod schemas. This ensures the UI never breaks.
- **Safety First**: An `injection-guard` middleware strips out manipulative prompt patterns before they reach the model.
- **Graceful Degradation**: If the Gemini API fails or rate-limits, the backend seamlessly falls back to pre-programmed deterministic responses so stadium operations are never interrupted.

## 🚀 How the Solution Works
1. **Fan Concierge**: Fans ask questions in natural language. The backend injects stadium data, detects the user's language, and returns a translated, context-aware answer (with full RTL support for Arabic).
2. **Operations Command Center (Venue Management)**: IoT sensors (simulated via API) send telemetry. The backend aggregates this and prompts Gemini to act as a security analyst, returning a formatted briefing with priority-ranked actions for crowd control.
3. **Volunteer Digest (Staff Operations)**: Staff receive shift briefings generated by combining current weather, transit status, and relevant standard operating procedures (SOPs).
4. **Transit Advisor (Logistics)**: Fans input their origin, and Gemini evaluates current parking lot capacity, shuttle ETAs, and sustainability goals to recommend the optimal route, easing venue ingress/egress.

## 📝 Venue & Operations Assumptions
- **IoT Telemetry**: We assume stadium turnstiles and cameras are feeding occupancy data to the `/api/crowd/telemetry` endpoint to monitor crowd pressure.
- **Data Store**: Currently implemented as in-memory JSON files for hackathon simplicity, but architected to be instantly swapped with Google Cloud Firestore for a production deployment.
- **Hardware Access**: We assume venue staff have access to mobile devices to view the web app interface during shifts.

## 🏟️ What It Does

### For Fans — Multilingual Concierge
- **Multilingual Q&A** in English, Spanish, French, Portuguese, and Arabic (full RTL support)
- **Grounded on stadium data** — the model can't invent a gate number
- **Accessibility-aware routing** — wheelchair, low vision, deaf/HoH, cognitive support modes
- **Emergency escalation** — detects safety keywords and escalates to venue staff

### For Operators — Crowd Pulse Dashboard
- **Live zone density heatmap** with normal/watch/critical classification
- **AI-generated operational briefings** with prioritized, actionable recommendations
- **Sustainability metrics** — waste diversion, energy, and water status
- **"Simulate a Spike" demo** for dramatic live scenarios

### For Volunteers — Ops Digest
- **Shift-start briefings** generated from context feeds (weather, transit, crowd forecast)
- **SOP-grounded Q&A** — every answer cites the procedure it came from
- **Escalation detection** — emergency procedures displayed verbatim from SOPs

### For Transit — Smart Recommendations
- **Per-origin transit advice** using real shuttle/parking data
- **Sustainability notes** — informative, never preachy
- **Post-match timing advice** to avoid exit surges

## 🧠 AI Architecture

```
Fan/Operator/Volunteer → Hono API → Injection Guard → Prompt Builder → Gemini API
                                                                           ↓
                                              Zod Validation ← JSON Response
                                                    ↓
                               Structured Response / Deterministic Fallback
```

- **Prompt engineering**: 4 competition-grade prompts with anti-injection clauses
- **Grounded generation**: Gemini receives structured stadium data, not free-form context
- **JSON mode**: `responseMimeType: application/json` enforces parseable output
- **Zod validation**: Every response validated against a typed schema
- **Deterministic fallback**: If Gemini fails, users still get helpful (honest) answers

## 🚀 Quick Start

### Prerequisites
- Node.js 20+
- A Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey)

### Setup

```bash
# 1. Clone and navigate
cd concourse-ai

# 2. Configure environment
cp .env.example backend/.env
# Edit backend/.env and add your GEMINI_API_KEY

# 3. Install and start backend
cd backend
npm install
npm run dev
# Server starts on http://localhost:8080

# 4. Install and start frontend (new terminal)
cd frontend
npm install
npm run dev
# App opens on http://localhost:5173
```

### API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | AI health check |
| GET | `/api/stadiums` | List all venues |
| GET | `/api/stadiums/:id/zones` | Get zones for a stadium |
| POST | `/api/concierge/chat` | Multilingual fan Q&A |
| POST | `/api/crowd/telemetry` | Ingest zone telemetry |
| GET | `/api/crowd/briefing` | AI operational briefing |
| GET | `/api/ops/digest` | Volunteer shift briefing |
| POST | `/api/ops/ask` | SOP-grounded Q&A |
| POST | `/api/transit/recommend` | Transit recommendation |

## 🌐 Multilingual & RTL

The concierge detects fan language automatically. Arabic responses include:
- `text_direction: "rtl"` in the API response
- CSS Logical Properties (`margin-inline-start`, `border-end-end-radius`)
- Font switching to Noto Sans Arabic
- Chat bubble alignment flip (user messages go left, AI goes right)
